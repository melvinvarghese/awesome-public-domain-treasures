# Research log: literature, scores, and photography

Verification date: 2026-10-30. This batch contains 20 individually identified works. Descriptions are original. Source titles are sometimes shortened for navigation; catalogue descriptions and creator attributions remain authoritative. Dates identify the original work or linked historical edition, not the Gutenberg ebook release, except that the Thomson photograph explicitly distinguishes its later print.

## Method and scope

- Project Gutenberg: searched/opened the primary ebook catalogue record and its actual linked HTML ebook; inspected the standard US reuse header, creator/translator information, and relevant contents. The catalogue explicitly reports public domain in the USA. Headers did not show an item-specific permission-only grant. Gutenberg's generic licence also discusses books posted by permission; that generic conditional clause is not an item-specific copyright claim. These are labelled **Public Domain — United States**, never worldwide. The underlying texts and historical editions are the objects of the entries; Gutenberg branding/trademark and compilation conditions remain separate. Policy: <https://www.gutenberg.org/policy/license> and <https://www.gutenberg.org/policy/terms_of_use.html>.
- Wellcome: opened each of the five full primary item records. Each explicitly labels the digitised work **Public Domain Mark** and supplies JPEG downloads. This supports the Public Domain label rather than an inference from age. Anonymous makers remain null. Historical photography can reflect colonial collecting practices and should be read critically; public-domain copyright status does not resolve every ethical reuse issue.
- Library of Congress: primary-source web search returned the full indexed item records, including bibliographic metadata, formats, and the **Rights & Access** paragraph. All four selected records explicitly describe their sheet-music collection as public domain and free to use and reuse. Direct open requests returned HTTP 403, so this batch does **not** claim an independent live full-page fetch of those four records. Indexed primary text was the accessible evidence. This is stronger evidence than a bare “no known restrictions” advisory, which was not used as the sole basis for inclusion. Rights are conservatively labelled United States.
- NYPL: opened the complete Daisy Bell item page and inspected its item-specific US public-domain statement and 1892 publication metadata. It explicitly reserves judgment outside the United States. The linked resource is the historical score, not a modern audio recording.

## Exclusions and limits

- Excluded a LOC steamship photograph because “no known restrictions” and a mixed collection-level statement did not meet this project's strict admission threshold.
- Excluded LOC's Black crook galop despite an explicit public-domain paragraph because the retrieved creator authority metadata had an apparent anachronism (a 1926 birth paired with an 1866 score). No guessed correction was substituted.
- Excluded the LOC Maple Leaf Rag record because its retrieved rights paragraph was generic, without the selected collection's explicit public-domain wording.
- Cleveland's API returned 403 and its Talbot item page timed out; neither is represented as verified in this batch.
- These checks do not establish worldwide copyright status, test every downloadable binary, or give legal advice. Formats mean that the source offered those access options, not that every asset was downloaded and tested.

## Supplementary access check

Python standard-library HTTP GETs independently fetched all ten actual Gutenberg HTML ebooks with HTTP 200. The inspected pre-text header of every ebook contained the standard US reuse wording; none contained an item-specific permission-based notice. This is a limited header check, combined with catalogue rights labels and historical-edition metadata, rather than an assertion that an automated phrase match proves copyright status. A machine-readable working record was saved as `pg_check.json` outside the curated data. The catalogue formats HTML, EPUB, and plain text were also visible in the primary catalogue records.

## Final direct-access follow-up

After the initial research, the parent reviewer retrieved all four LOC score pages successfully with the link auditor’s request headers. Each returned HTTP 200, a full HTML page exceeding 160 KB and explicit public-domain text. The earlier HTTP 403 observations remain accurate for those initial requests; they were access-dependent rather than proof of dead records. [Follow-up results](loc-live-checks.json) record the checks. This resolves the initial indexed-only access limitation for this release while preserving its research history.
